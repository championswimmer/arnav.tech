# arnav.tech

The personal website of **Arnav Gupta** — a sepia, "written" personal site for
essays, technical writing, and project showcases. Built with [Astro](https://astro.build).

See `AGENTS.md` (symlinked as `CLAUDE.md`) for the full design language, content
model, and authoring conventions.

## Commands

All commands are run from the root of the project, using **bun**:

| Command             | Action                                    |
| :------------------- | :---------------------------------------- |
| `bun install`         | Installs dependencies                     |
| `bun run dev`         | Starts local dev server at `localhost:4321` |
| `bun run build`       | Build the production site to `./dist/`    |
| `bun run preview`     | Preview the build locally before deploying |
